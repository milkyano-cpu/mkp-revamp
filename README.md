# MKP Bikes — website revamp

A redesign of [mkpbikes.com.au](https://www.mkpbikes.com.au/) in the style of [cowboy.com](https://cowboy.com/): full-bleed photo heroes, large tight headlines, pill buttons, "+ feature" chips, and alternating light and dark sections. It's built as a clean e-commerce storefront.

Plain HTML, CSS and JS with no build step.

## Run it

```bash
python3 -m http.server 4173 --directory mkp-revamp
```

Then open http://localhost:4173. The Code tab preview uses `.claude/launch.json`, which runs the same command.

## Pages

| Page | What it is |
|---|---|
| `index.html` | Home page: hero, featured-bike slider, Tavelo feature, trust row, scroll-reveal statement, shop grid with tabs, bike fitting, test ride, size finder, customer photo strip, journal, "keep exploring" tiles |
| `shop.html` | All 67 listings. Type tabs plus category, size, brand and price filters, and sort. Filters are kept in the URL (`?type=pre-owned&category=TT`). `?fav=1` shows saved bikes |
| `bike.html?slug=…` | Product page: photo gallery with lightbox, sticky buy box, condition breakdown, description, specs table, related bikes |
| `tavelo.html` | Tavelo dealer page: complete bikes, framesets and wheels, warranty, crash replacement, FAQ |
| `fitting.html` | Bike fitting with Ash Saxena: the 5-step process, pricing, add-ons, testimonials, FAQ |
| `sell.html` | Sell or trade-in. The form builds a WhatsApp message with the bike's details |

## How e-commerce works here

MKP sells through WhatsApp, not online checkout, so the bag is a **reservation bag**:
- **Add to bag** saves the bike in the browser (localStorage).
- **Reserve on WhatsApp** opens a chat to +61 478 165 043 with the bike list and total already filled in.

Favourites and the size finder (height and inseam to a frame size, linked to matching stock) also run in the browser.

## Content and assets

All copy, prices, specs, descriptions and photos come from the live mkpbikes.com.au site (scraped 23 Oct 2026):
- `js/data.js`: the full catalogue (53 pre-owned and 14 new listings). It was generated by a script, so to change a bike, edit the data and regenerate rather than editing by hand.
- `assets/bikes/`: up to 5 photos per bike, resized to 1200px.
- `assets/site/`: logo, hero, showroom, fitting and Tavelo images.
- `assets/reviews/`: the 21 customer photos from the home page.

## Before going live

Some things still need checking or replacing:
- Fonts are Google Fonts: Inter, Inter Tight, and Poppins for the `mkp.` wordmark. Cowboy uses Suisse Intl, which needs a licence.
- The newsletter form only shows a confirmation message. Connect it to MKP's Klaviyo account.
- Journal cards link out to the live MKP articles.
- Prices and stock are a snapshot. Connect `js/data.js` to MKP's real product API or CMS before launch.
